# layer-paint

單檔 HTML 繪圖程式（適合鉛筆素描描圖）：多圖層、HB/6B 紙紋鉛筆（筆壓、側鋒）、匯入底圖並變形、畫布旋轉、手勢復原、QuickShape 直線、滴管、磁力描邊、透視輔助線、3D 柱體與人偶。支援 Apple Pencil。

- **底圖**：匯入的參考圖預設鎖定（🔒，解鎖要確認），頂部工具列的「👁️ 底圖」可一鍵顯示／隱藏。
- **滴管**：取的是眼睛看到的那個顏色（區塊取樣＋墨量加權），取完停在滴管可連續取色。
- **磁力描邊（M）**：沿著輪廓拖曳，線會吸附到最強的邊緣，放手即完成一筆（可復原）；吸附半徑與平滑度可調。
- **透視輔助線**：黃點＝地平線高度（兩端各一顆）、紅／綠＝消失點（可上下移動整條地平線）、藍＝三點透視的第三消失點。

Demo: https://cormort.github.io/layer-paint/
