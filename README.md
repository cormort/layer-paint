# layer-paint

單檔 HTML 繪圖程式（適合鉛筆素描描圖）：多圖層、HB/6B 紙紋鉛筆（筆壓、側鋒）、匯入底圖並變形、畫布旋轉、手勢復原、QuickShape 直線、滴管、磁力描邊、透視輔助線、3D 柱體與人偶。支援 Apple Pencil。

- **底圖**：匯入的參考圖預設鎖定（🔒，解鎖要確認），頂部工具列的「👁️ 底圖」可一鍵顯示／隱藏。
- **匯入時背景是空的**（只有白紙）：會問一次「合併到背景」還是「另開底圖圖層」。
  合併到背景＝圖片直接疊在背景的白紙上、不多一層；選另一邊就是原本的行為。
- **滴管**：取的是眼睛看到的那個顏色（區塊取樣＋墨量加權），取完停在滴管可連續取色。
- **磁力描邊（M）**：沿著輪廓拖曳，線會吸附到最強的邊緣（游標旁有放大鏡），放手即完成一筆（可復原）；
  吸附半徑、平滑、描完填色（封閉路徑＋填色濃度）可調。
- **油漆桶（G）**：點在封閉區域就填滿前景色；容差、收邊（防漏）、填色濃度、只填相連區域可調。
- **透視輔助線**：黃點＝地平線高度（兩端各一顆）、紅／綠＝消失點（可上下移動整條地平線）、藍＝三點透視的第三消失點。
- **上方工具列的順序**：復原／重做 → 筆刷（筆刷種類＋鉛筆硬度，跟右側面板雙向同步）→
  常用功能（匯入底圖、底圖顯示、存專案、匯出 PNG、新畫布、開專案、版型）。
  左側工具箱已經有的（各工具、筆刷大小／不透明度、縮放）不在上方重複。
  視窗變窄會自動收：先收「整體／局部＋縮放」（文件標籤列與導航器都有同一組），
  再窄就把檔案／版面／視角收進右側「⋯」，所以任何寬度都不會橫向溢位、也不用左右滑。
